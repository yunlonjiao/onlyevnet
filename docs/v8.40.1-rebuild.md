# OnlyEvent v8.40.1 — rebuild specification

Recovery branch: `redo/v8.40.1` (based on `archive/template02-v8.38.3`). Do not merge to main until working previews and export are verified.

## Shared CMS contract (not a visual template)
- Preserve Template 01 functional capability: home, booths/products, activities, schedules, guests, guide, map, community, sponsors and optional custom pages.
- Keep inline yellow-field editing **and** clicking the blank area of a card to open the complete right-side editor.
- Preserve relationships among activities, schedules and guests, featured activities, favorites, wishlist, search, image lightbox and desktop/mobile responsiveness.
- Hero title is editable; it does **not** need three visible lines. Hero font sizes, colors and accents are driven by design, not global mandatory fields.
- Featured activities should use existing activity records; do not require exactly three featured cards.
- Map link targets use internal page/item targets.
- Publish Website and Export HTML reuse Template 01's common Publisher/export pipeline. Do not expose Cloudflare/GitHub implementation choices as visitor-facing publish actions.
- Visitor-facing site must never display design notes or template-design explanation text.
- Event end state is driven by configured end datetime; preserve existing override behavior.

## Four genuinely different template renderers
1. **02 — 18TRIP-inspired**: immersive editorial/travel visual storytelling, deliberate landing animation and mobile composition; not Template 01 blocks recolored.
2. **03 — COMITIA-inspired**: Japanese doujin catalog/wayfinding hierarchy, prioritizing creators, circles and navigation.
3. **04 — Design Festa-inspired**: creator-market editorial, visual portfolios and asymmetrical composition.
4. **05 — MUTEK-inspired**: lineup-first music/event composition with schedule and guest prominence.

Keep Template 01 regression tests green.
