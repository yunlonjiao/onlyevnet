# 模板参考的真实网站

每个模板的版式都对照一个真实的网站来做，只借用页面结构和排版方式（布局、导航形式、版块顺序、卡片形态），不使用对方的图片、文字和标志。配色沿用各模板原来的设计，不属于相似度判断的范围。

| 模板 | 参考网站 | 借用的内容 |
|---|---|---|
| 01 流行嘉年华 | 原有设计 | 左标题右贴纸大图、粗描边、硬阴影、快捷入口卡片 |
| 02 旅途手账 | 原有设计 | 手账式整屏主视觉、行程目录、拍立得人物卡 |
| 03 创作者集市 | 哔哩哔哩首页 https://www.bilibili.com/ | 白色顶栏加粉色操作按钮；顶部一条窄横幅，标题压在图上；频道胶囊一行；主体是左边轮播大图、右边六张作品的随机推荐，右上角「换一换」可重新洗牌 |
| 04 创作者场刊 | COMICUP 活动页（无差别同人站）https://www.allcpp.cn/ | 深色顶栏；整宽横幅；面包屑行；下划线标签页；电子场刊作为主面板 |
| 05 舞台现场 | Love Live! 演唱会特设站 https://www.lovelive-anime.jp/yuigaoka/live/sp_1stlive/ | 居中标志的页头；整宽标题条；竖版主视觉加标题和「日程 / 会场」表；一排标签按钮；每个公演日一张底色卡片 |
| 06 乐队演出 | 新宿 LOFT 日程页 https://www.loft-prj.co.jp/schedule/loft | 黑色顶栏；墨点喷溅的白纸底；左侧竖排「TODAY'S EVENT」日期栏；传单作为主图 |
| 07 茶会小聚 | animate cafe 活动页 https://www.animatecafe.jp/ | 页头加一行带分隔线的文字标签；居中的大标题；居中的主视觉卡片，下面是日期 / 地点表；状态圆标；弧形顶部的卡片面板；悬浮的圆形报名徽标 |
| 08 生日应援 | Sanrio 官网 https://www.sanrio.co.jp/ 和 animate cafe 生日联动页 https://www.animatecafe.jp/event/ac000660 | 柔和的弧形页头；圆形照片压在弧线上；胶囊按钮；点线分隔；页脚的「PAGE TOP」圆弧凸起 |

首屏的构图、图片占比、倾斜、边框和边缘分布由 `quality/tests/design-distinct.spec.mjs` 自动检查，任意两个模板不能做成同一种首屏。
