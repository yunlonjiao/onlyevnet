# OnlyEvent Studio

Online site builder for small and mid-size doujin / IP-only conventions: organizers
register at `/admin/`, create an event, pick a template, edit it in `/v8/`, then publish to
`<slug>.onlyevent.cn`.

- Live organizer platform: https://onlyevent.cn/admin/
- Worker + D1 + R2 backend: `cloud/` (`src/worker.js`, `schema.sql`, `wrangler.jsonc`)

## Releasing a change

```powershell
.\cloud\scripts\ship.ps1           # git push + Verify + Deploy (Deploy asks for "yes")
.\cloud\scripts\ship.ps1 -Force    # unattended
.\cloud\scripts\ship.ps1 -NoPush   # deploy only
.\cloud\scripts\ship.ps1 -Rollback # back to the version recorded before the last deploy
```

Deploy records the live Worker version, exports production D1 to
`Documents\OnlyEvent-backups\<date>\`, runs `npm run deploy` (rebuilds `cloud/web` from the
repo root, checks, tests, `wrangler deploy`) and verifies onlyevent.cn afterwards.

Runbook, smoke checks and troubleshooting: [docs/cloudflare-worker-deploy.md](docs/cloudflare-worker-deploy.md).

## Layout

| Path | What it is |
|---|---|
| `admin/` | organizer platform (projects, template library, sign-in) |
| `v8/` | Studio editor, renderer and visitor templates |
| `collect/`, `signup/` | public forms (club submissions, staff applications) |
| `cloud/` | Cloudflare Worker: API, publishing, visitor sites, scheduler |
| `quality/`, `tests/` | Playwright suite and shared editor tests |

`cloud/web/` is generated by `cloud/scripts/sync-web.mjs` from `admin/`, `v8/`, `collect/`
and `signup/`; it is git-ignored and never edited by hand. Static preview needs no build:
open `index.html`.
